杯杯 v1.0.2 · 一只非常欠揍的桌宠

打开
Windows x64：解压“杯杯-Windows-x64.zip”的整个文件夹，双击 Beibei.exe。
请把整个 ZIP 发给同学，不要只发 exe；运行不需要 Node、Python 或其他开发工具。
Mac Apple 芯片：解压“杯杯-Mac-Apple芯片.zip”，打开“杯杯.app”。可拖入“应用程序”。
Mac 包需要 macOS 13 或更新版本，适合 M1/M2/M3/M4 等 Apple 芯片；此包不适用于 Intel Mac。
Windows 包面向 Windows 10/11 的 64 位 Intel/AMD 电脑；不适用于 32 位 Windows。

怎么玩
• 平时闭眼噘嘴、晃腿溜达，偶尔说“我不告诉你～我不告诉你～”“你太low辣！”“杯杯我呀～”。
• 移动鼠标：杯杯嘴欠搭话，7 秒冷却，不会每移动一点就刷屏。
• 单击杯杯：正面贱笑，掉一坨便便在旁边。
• 拖便便到杯身中央，松开：陶醉吃掉，感叹“这……这是什么人间极品……！！”，接着“亚米亚米～”。
• 拖动或长按杯杯：正面惊恐乱蹬，喊“爸爸我错了！！”，不断掉出便便。
• 拎住约两秒：便便绕着杯子转，外围逐渐长出棕色大便圈和彩虹大便圈。
• 松手：便便向四周炸开；杯杯最多往下掉 72 像素，摔成碎片，几秒后在原处拼回来继续嘴硬。
• 单击生成的便便最多保留 10 坨，闲置 90 秒自动清理；环绕与爆炸便便会自行消散。

管理
右键杯杯，或点菜单栏 / 系统托盘里的小杯子：
静音、允许溜达、再嘴欠一句、找回杯杯、清理便便、玩法说明、退出。
Ctrl/⌘ + Shift + B：把杯杯叫回主屏幕。
拖着便便喂食时，杯杯会暂时站住，免得追不上它。

声音
默认有声音，可以从菜单静音。优先使用电脑自带的本地中文语音；如果没有可用的本地中文声音，改为卡通叫声，文字气泡始终保留。

分发与已知限制
这是未做商业签名 / Apple 公证的自制版本，首次运行可能出现系统的来源确认。
Mac 已完成实际启动与动画截图检查、逻辑自动测试；Windows 已完成打包、可执行文件及资源完整性检查，目前没有 Windows 真机测试。
运行时完全本地工作，不需要账号、网络、管理员权限、屏幕录制权限或辅助功能权限。首次设置只记录静音和溜达开关。
macOS 13 最低版本依据：https://www.electronjs.org/blog/electron-44-0

卸载
先通过菜单退出，再删除解压的文件夹或“杯杯.app”。此程序不会自行添加开机启动。

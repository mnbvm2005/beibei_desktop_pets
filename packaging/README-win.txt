杯杯 · Windows x64 便携版

1. 完整解压 ZIP。
2. 双击 Beibei.exe。
3. 右键杯杯 / 点系统托盘小杯子，可以静音、找回、退出。

不要只复制 exe。把整个 ZIP 发给同学，解压就能运行，不需要安装开发工具。

单击：正面贱笑，掉一坨在旁边。拖便便进杯子：喂食。
拖动 / 长按杯杯：惊恐求饶、持续排便，棕色与彩虹便便双环。
松手：便便炸开，杯杯只短落一截，摔碎后原地复原。
鼠标移动：会嘴欠搭话，7 秒冷却。

声音优先使用本地中文语音；系统缺少中文声音时使用卡通音效。
此自制版本尚未商业签名，首次打开可能出现来源确认。
本包面向 Windows 10/11 x64，尚未进行 Windows 真机测试。
详细玩法见同包“杯杯-使用说明.txt”。
